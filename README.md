# 💨 Karnataka AQI Monitoring Dashboard

A modern React-based Air Quality Index (AQI) monitoring dashboard for Karnataka districts and talukas.

The application provides district-wise and taluka-wise AQI visualization with pollutant analysis, weekly trends, comparison charts, and responsive UI components.

---

# 🚀 Features

* Karnataka district selection
* Taluka-wise AQI monitoring
* Real-time ready AQI architecture
* Pollutant visualization

  * PM2.5
  * PM10
  * NO2
  * O3
* Weekly AQI trend graph
* District comparison charts
* Taluka comparison charts
* Responsive mobile-friendly design
* Modern dashboard UI
* API-ready structure

---

# 🖥️ Dashboard Modules

## 1. Get Started Page

A clean landing page introducing the Karnataka AQI Monitoring platform.

## 2. District & Taluka Selection

Users can:

## 3. Pollutant Visualization

Interactive charts displaying:

* PM2.5
* PM10
* NO2
* O3

## 4. AQI Trend Analysis

Weekly AQI trend graph using SVG visualization.

## 5. Comparison Analytics

* Top AQI districts
* Taluka AQI comparison

## 6. Technology Overview

Displays technologies used and application architecture.

# 🏗️ Architecture

User → React Frontend → Data Processing Layer → AQI API → Visualization Engine

### Components

* **Frontend**

  * React JS
  * Responsive UI
  * Reusable components

* **Data Layer**

  * AQI processing
  * Taluka filtering
  * Chart data generation

* **Visualization**

  * SVG graphs
  * Bar charts
  * Comparison analytics

* **API Layer**

  * CPCB API
  * OpenAQ API
  * WAQI API support

# 📦 Installation

Clone the repository:

```bash
git clone https://github.com/Chethan-MO/AQI.git
```

Move into project directory:

```bash
cd AQI
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm start
```

---

# ⚡ Build for Production

```bash
npm run build
```
